# NurseTrack Enterprise

Foundation for the next-generation NurseTrack clinical platform.

## Architecture

- Kotlin + Spring Boot
- PostgreSQL
- Modular monolith
- REST API first
- Audit-ready clinical records
- Role-based access control
- Docker-ready deployment
- Future HL7/FHIR integration layer

## Initial modules

1. Identity and access
2. Companies and memberships
3. Patients and demographics
4. Encounters / visits
5. Nursing
6. Social Work
7. Medicine
8. Billing
9. Documents
10. Audit

This branch is intentionally isolated from the current production/v4-beta application. No existing clinical data is modified by this scaffold.
